# APPYouzhisan

## Project Structure

- `chenghua-app/`: Vue + Vite frontend
- `chenghua-backend/`: Spring Boot backend

## Frontend

```bash
cd chenghua-app
npm install
npm run dev
```

## Backend

```bash
cd chenghua-backend
mvn spring-boot:run
```

## Environment

- Backend AI key: set `BIGMODEL_API_KEY`
